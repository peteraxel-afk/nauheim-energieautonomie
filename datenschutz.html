Datenschutzhinweise für den aktuellen technischen Stand der Projektwebsite.

2 · Hosting über GitHub Pages

Diese Website wird über GitHub Pages bereitgestellt. Beim Besuch einer GitHub-Pages-Seite wird nach Angaben von GitHub die IP-Adresse des Besuchers zu Sicherheitszwecken protokolliert und gespeichert. Darüber hinaus können technisch erforderliche Verbindungs- und Nutzungsdaten beim Hostinganbieter anfallen.

3 · Interaktive Karte / OpenStreetMap

Auf der Seite „Karte & Standorte“ werden Kartenkacheln von OpenStreetMap geladen. Beim Anzeigen der Karte stellt der Browser hierfür eine Verbindung zu Servern der OpenStreetMap Foundation her; dabei werden technisch notwendige Verbindungsdaten, insbesondere die IP-Adresse, übertragen. Die Karte übermittelt keine vom Nutzer eingegebenen Standortdaten und bietet keine Ortungsfunktion. Für die Kartenfunktion wird die Leaflet-Bibliothek derzeit über das CDN unpkg.com geladen; dadurch entsteht beim Aufruf der Kartenseite zusätzlich eine Verbindung zu diesem Anbieter.
